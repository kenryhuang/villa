# 社交、日程与地图闭环

## 日程执行

最新 `farm3d-65bc261e29818-1077600f1a1-1789740284-3536846.ndjson` 的 10 次 `schedule_conflict` 都发生在同一批动作中：前一个 `start_leisure` 仅创建了进行中的活动，却回报 completed，后一个动作立即抢占同一个人。

`start_leisure`、`start_learning` 现在回报 in_progress。执行器按真实活动状态生成最终 completed/failed 回执，复用既有 continuation 依次执行后续动作。期限到达、伙伴不可用等取消活动时停止后续动作；重复轮询不重复完成。存档同时保存活动和待续批次。`self/activity` 返回当前活动、剩余作业分钟和期限；剩余分钟不包含尚未完成的步行。真正被其他活动占用时仍拒绝并返回日程详情。

## 地点查询

`scripts/farm3d/named_places.gd` 统一区域名称、别名、地图标签和导航落点。包括农庄、村庄、林地、丘陵、山地、峡谷、平原、河岸、木桥、沙地、南湖及三处湖岸、球场、市集、旅店、合作社。

先 discover map，再 `query_map({query:"南湖"})`；也兼容 `query_world({domain:"map",section:"regions",query:"南湖"})`。精确 ID、中文名和别名优先，模糊查询可返回多个地点。每页最多 10 项，主要目的地含球场在首页，`next_cursor` 获取其余地点。

查询实时检查导航格和从当前角色出发的路径；已被建筑占用的落点寻找附近可走格。返回 `position`、`reachable`、`distance`、`arrived` 和可直接提交的 `navigation_action: move`。无路时不提供可执行动作。南湖定位岸边，球场定位实际入口。旅店目前沿用已有市集服务点，不虚构独立建筑；调查仍只支持既有三处调查点。

## 好感和关系

每对角色保存双向好感（0–100）、共同经历次数、正式关系、提议和冷却。机构账户不参加。只按已成交交易、已履行承诺、实际共同活动、完成拜访/陪伴/约会、当面表达的安慰结算，不因排队、报名或未兑现的承诺加分。

| 经历 | 基础增量 |
| --- | --- |
| 私人成交 | 双方 +1 |
| 履约 | 双方 +3 |
| 主办活动获得参与 | 双方 +1 |
| 实际共同参加活动 / 拜访 | 双方 +2 |
| 完成陪伴 / 约会 | 双方 +4 |
| 当面安慰 | 接受者 +3，表达者 +1 |

同对角色每天最多使用 8 点增量，同类最多计 2 次；同一事件幂等。公开活动的主办关系不替代真实私人相处。好感与既有合同信任分开保存。

双方成年、单身且愿意时可以先约会，不要求正式关系或好感门槛。已有恋人可以继续相互约会；不会同时与第三人发展约会关系。正式恋人确认需要双方好感至少 60、至少 3 次私人相处以及双方明确意愿。拒绝不扣分，一日内不反复追求；任一方可结束关系。

无恋爱按钮、关系面板或确认卡片。`propose_relationship` 表达 NPC 意愿，`respond_relationship` 处理 NPC 间回应。对玩家，用 `resolve_relationship_dialogue` 记录当轮对话里的明确确认、拒绝或分手；引用必须完全匹配当前输入，执行期间绑定发起 NPC/请求，结束即清空。普通邀约、好感表达和不明确答复不应当作确认；判断有歧义时继续对话。后台循环不能提供玩家同意。关系、性格和提议按需通过 actors 查询，进入后续对话记忆。

角色年龄、性格、恋爱兴趣及偏好在 `data/living_world/social_profiles.json`；年轻女性有不同的交往风格和自主意愿，职业目标继续保留。重点 NPC 由 LLM 自主回应，背景居民按各自偏好延迟回应，玩家通过实际对话回应。感情陪伴压力持续保存，真实相处缓解压力。

世界存档升级到版本 8，旧存档缺少关系数据时初始化为空，不重置经济和农田、不补发历史好感。测试使用隔离存档，包括复制现有存档验证迁移。
