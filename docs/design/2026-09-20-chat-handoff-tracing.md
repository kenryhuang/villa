# 聊天行动提取与行动 context 追踪

Agent 跟踪窗口在 Input、Reasoning、Output 旁增加“行动指示”页。聊天筛选窗口也保留关联行动请求的证据，无需把所有 NPC 后台请求混入聊天列表。

## 展示与证据

- 原始提取输出（包括无效 JSON 和被截断的输出）、候选、通过校验的结构化指示、逐条拒绝原因。
- 服务端归档及可信交接校验结果；客户端暂停、每日额度、现有工作等等待原因。
- `provider.input` 的实际 `messages[].content → turn.dialogue_followups` 是进入行动 context 的证据。记录目标请求 ID、模型、调用索引和原始交接片段，并关联回 `dialogue:<聊天请求 ID>`。
- 仅排队、归档、计划复核不标记送达。进入 context 也不代表行动已经执行。旧记录和缓存缺少原始提取调用时明确标记。
- 提取证据中的聊天原文只在聊天调试记录展示；行动 context 继续仅使用服务端归档的游戏字段。

## 提取修正

地图命名区域不包含玩家温室等建筑实例。对涉及建筑的对话按需查询建筑目录，让提取器使用真实实例 ID 和所有者。行动 loop 据此查询建筑实时位置。独自前往明确地点的 `visit` 不再强制要求同行对象；没有对象也没有地点仍被拒绝。

提取提示明确区分移动约定、闲聊和已经完成的行动；回复同时包含情绪或叙述时仍提取明确同意的出发，重新确认出发也不因前文提过就忽略。

### 地点与行为的双向约定

> 以下为 9 月 20 日版本；9 月 21 日已按用户要求改为滚动摘要与严格单轮提取，最新设计见 [聊天摘要与单轮行为提取](2026-09-21-chat-summary.md)。

客户端通过 `chat_focus_actors` 提供当前重点角色 ID 和显示名；聊天与提取目录只保留当前角色和这些重点角色的简短姓名信息，不发送全体居民人设。群聊仍保留实际参与者的发言和署名。

提取器读取最多 12 条近期消息（历史文字上限 6000 字，保证保留本轮玩家消息），另外加入当前 NPC 回复；普通聊天仍维持原有 6 条、1800 字的历史限制。每条提取输入有 `speaker`，本轮玩家消息带 `current`。这样 NPC 上轮提出“去南湖散步”，玩家本轮只说“好”，仍能读取完整提议和同意。

模型输出简化为 `place_id/activity/status/target_actor_id/player_evidence/actor_evidence`，可选延迟。双方均可发起提议；玩家主动提议无需额外再次确认。玩家证据必须来自本轮玩家，角色证据可来自当前 NPC 的早先提议；群内别人的同意不能替代双方意愿。地点用目录唯一 ID，行为用有限枚举；温室等建筑还区分所有者。服务端补齐原有交接字段，并保留 `activity` 供行动模型安排抵达后的具体行为。聊天证据不进入行动 context。

问路后 NPC 新提出邀请不等于玩家已答应；明确拒绝、假设和已完成往事不生成新行动。提示包含这些反例与完整 JSON 示例。商品、数量、坐标等执行细节交给行动 loop 按需查询，不要求小模型一次生成完整动作参数。模型仍承担语义判定，证据校验只验证来源和字段，不能保证每次语义判断正确。

## 验证

- 服务端全量：171 通过，1 跳过。新增通过真实 HTTP mock provider 验证提取字段与行动模型实际接收的请求完全一致，聊天原文不进入行动 context。
- Godot Agent：1786 项通过；交接运行期：30 项通过；分离聊天：34 项通过。覆盖重点角色名单、行为字段的客户端接收、存档恢复和下一轮行动 context。
- 独立本地模型探针使用当前配置的聊天模型及测试世界目录，两例（同行去温室、独自去市集）均提取成功；记录位于 `tmp/handoff-live-probe.json`。没有读写真实玩家状态。
- 新规则使用同一本地模型 `cydonia-24b:latest` 实测：上轮 NPC 提议后玩家说“好”、玩家提出去温室看作物、玩家拒绝、玩家问路后 NPC 新邀请，4 例均通过。记录 `tmp/chat-agreement-live-probe.json`。首轮发现模型在 JSON 后追加解释、误把问路后的邀请当成双方同意；加强纯 JSON 要求及对应反例后复测通过。该结果证明这些样例，不代表模型在所有自然语言变体下都可靠。
- 实际渲染的行动指示页：15 项检查通过，截图 `tmp/handoff-trace-ui.png`。截图使用明确的测试请求和测试模型名。

服务端修改通过重启 Agent Service 加载；客户端新页与调度诊断需重新运行游戏。未开启追踪文件保存的历史运行不能补回原始提取详情。
