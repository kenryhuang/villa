# 建筑地理约束与钓鱼闭环验证

验证日期：2026-08-30  
分支：`feature/painted-production-buildings`

## 已实现范围

- `GeographicQueryService` 统一天然水域岸线、水锚点、成熟花卉半径和抛竿线路查询；灌溉状态不能冒充天然水域。
- 建筑放置和生产系统共享同一个地理查询实例，水车必须正交临水；成熟花会按距离和稳定建筑键最多供给两个蜂箱。
- 蜂箱无成熟花时停产；1 朵产 1 蜂蜜，2–3 朵产 2 蜂蜜，4 朵且至少两种花时产 2 蜂蜜和 1 蜂蜡。
- 加入溪鲫、河鲈、鲤鱼、虹鳟、夜鲶和唯一漂流瓶，以及烤鱼、腌鱼加工品。
- `common_fish` 标签配方会在生产预检时按稳定物品 ID 顺序解析并立即锁定、扣除具体普通鱼堆；稀有鱼不会被误消耗。
- 世界固定生成四个溪流鱼点；钓鱼使用现实秒状态机，只有活动会话推进。
- 投竿前先无副作用检查鱼竿、体力并预留鱼获背包容量；鱼竿耐久和体力只在投竿表现结束、正式进入等待咬钩时提交，原来的随机纤维奖励路径已移除。
- 成功收杆把一件产物真实写入背包；同一会话不能重复结算；每点每天最多成功三次。
- 鱼点成功数、投竿序号、重置日和唯一产物状态写入 `fishing_state`，公开 JSON 读档会把整数型浮点数规范化回整数。

## 玩家操作

1. 按 `P` 进入种植模式。
2. 按数字键 `5` 选择鱼竿。
3. 靠近溪流岸边的半透明蓝色鱼点并左键点击，开始投竿。
4. 等待消息栏出现“咬钩了”后再次左键或按 `E` 收杆。活动会话中的收杆输入由钓鱼系统独占，不会触发移动或地块操作。
5. 换工具、换模式、取消选择、打开背包/商店/建筑面板、保存或加载都会安全取消当前钓鱼会话，释放预留容量并恢复移动输入。

## 存档行为

- 正式存档位置仍是 `user://villa_saves/save_<slot>.json`。
- 新字段为顶层 `fishing_state`，版本为 `1`。
- 活动钓鱼会话不保存；保存前先取消会话。已正式投出的耐久/体力不返还，尚未结算的鱼点成功次数不增加。
- 旧存档没有 `fishing_state` 时，四个鱼点从空的当日状态开始；若旧背包或收集记录已有漂流瓶，会回填唯一鱼获状态，避免重复获得。
