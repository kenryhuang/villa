# P12：36 人社会与长期稳定验证

2026-09-09，`feature/3d-farm-preview` 工作区。36人规模的规则、真实Agent、迁移、经济与性能自动化验收通过；人工全路线体验与更大规模保持待验证。测试均使用正式 3D 场景的隔离副本，未读取或修改 `data/farm_3d_save.json`。

## 当前开放规模与操作

正式游戏默认36名居民、4个组织、6名重点NPC。底部「调试 → NPC Agents」可以提升或降级重点角色，上限8名；已有工作、活动或请求未结束时不能切换，防止两个执行器重复履约。角色沿用原账户、关系、记忆和项目。远处居民用持久位置与日程模拟，附近最多复用3个普通居民模型。

合作社使用原种植系统经营80块真实田地。20个农务班次各照料4块田，另有4个旅店班次；每班工资30金币，完成180分钟工作及实际农务才领薪。种子消耗、季节、浇水、收获和上市均调用原规则。合作社与旅店使用有限初始资金，合作社初始种子为有限库存，不自动补钱或凭空生成食物。旧存档中的玩家建筑、田地优先保留；找不到合法农田空间时不会覆盖玩家资产。

人物外观仍沿用已有模型和普通居民占位模型，精细动作属于 TD-01。60/120人没有开放，也不作为本次通过承诺。

## 新增可玩循环

| 入口 | 操作与真实结果 |
| --- | --- |
| 集市旁公告板 → 配送与计划 | 提出配送/周期供货，NPC可拒绝、还价、接受；确认后托管，按实际取货、加工和送达结算 |
| NPC 对话 | 协商加工、分包、共同出资、学习和建筑维护；模型只有提交合法命令、双方接受后才能花钱 |
| 配送与计划 → 调查资助 | 选择河岸、林地或丘陵，提供2份面包及约定报酬；区分新报告、旧报告和必需样本条件 |
| 私人情报卡 | 核对报价并购买，解锁真实位置；免费分享、公开或已知信息不再收费 |
| 天气和商道卡 | 查看预报、在途货物与修复点；到场投入木材6、石料4及60分钟劳动，或等待自然恢复 |
| 活动卡 | 出资组织、报名、退出；实际到场消费食品，活动开始后收鱼或完成七洞可领取一次已拨款奖励 |
| 调试 → 居民社会 | 查看居民用餐、项目、公共预算、重点角色与当日规划额度 |

NPC目前只观赛，不生成虚构的NPC钓鱼或高尔夫成绩。工作、学习、探索、活动都占用同一角色日程；玩家不接委托也可以继续经营。具体条款与失败路径见 [P8](P8.md)、[P9](P9.md)、[P10](P10.md)、[P11](P11.md)。

## 请求和运行预算

### 2026-09-09 定时调度恢复

`AgentRuntime` 比 `LivingWorld` 更早收到 `time_changed`，此时社会模拟尚未追上新时间，`_build_request` 会拒绝私人 NPC 的定时请求。原先只有时间信号触发调度，社会结算完成后没有重试，因此连续推进游戏时间也可能一直没有定时请求；公共协调者在结算之后调用，不受此顺序影响。

运行时现在保留一次待调度标记，在社会结算完成且游戏未暂停时处理。多次时间推进合并到最新游戏分钟，处理后清除标记，不逐帧重复扫描全部角色。原来的角色间隔、忙碌过滤、重点角色名单、并发和每日预算继续生效；服务关闭时清除待调度标记。

隔离回归 `tests/run_3d_agent_scheduling_tests.gd` 使用正式场景和记录请求的替身网关，不访问模型或玩家存档。修复前稳定复现同步完成后漏调度；修复后默认36人场景14项、小规模场景13项通过，覆盖分帧结算、暂停恢复、实际帧回调、重复请求、每日额度、服务关闭及多个时钟信号合并。原 Agent 1707项、3D Agent集成57项、P12跨日结算与迁移51项通过。

```powershell
godot_console.exe --headless --path . --script tests/run_3d_agent_scheduling_tests.gd
godot_console.exe --headless --path . --script tests/run_3d_agent_scheduling_tests.gd -- --farm-test
```

### 现有预算规则

- 2026-09-10 调整：私人角色自主规划共享16次请求/游戏日、最多同时3个；公共协调者4次/日、同时1个。玩家对话单独保留1个名额、单独统计每日次数，暂不设游戏日次数上限。后台事件合并并轮换，超额延后到下一日；后台满载或额度耗尽不会占用对话名额。
- 本地服务配置 `provider.max_concurrency` 和示例值调整为5；缺省解析值仍为2，实际部署应显式设置。每个会话/游戏日预留预算8,000,000，按每轮请求UTF-8字节数、最大输出和模板余量保守预留，包含读取、纠错、重试及记忆压缩；这是预算单位，不是账单实际token，对话仍受此服务端总预算约束。

对话不再重置后台定时规划的间隔。更换同一 NPC 的对话仍会取消旧请求并忽略迟到结果；另一个 NPC 已占用对话名额时，拒绝新的对话，不误取消目标 NPC 的后台任务。连续更换对话保留已合并的后台事件。存档规划计数新增可选 `dialogue_calls`，旧版本7的 `{day, calls}` 继续读取，原有混合次数保守计入自主额度，新对话从0开始计数。调试面板「居民社会」显示两类每日次数和各类占用名额。

本次调整验证：`run_agent_concurrency_tests.gd` 33项、Agent系统1713项、定时调度13项、3D Agent集成57项、P12存读档与迁移51项全部通过；服务配置与对话优先测试12项通过，新增覆盖并发5时的抢占、恢复和峰值上限。规则测试不调用真实模型，尚未据此认定实际供应商的延迟或限流表现改善。服务配置重启 Agent 服务后生效，游戏端名额与独立额度在重新运行游戏后生效。
- 预算持久化到原SQLite旁的 `.provider-budget.json`；重启服务或倒退游戏时间不能重新领同日额度。真实模型的 `usage`、排队毫秒和当日预留量逐轮进入原trace，不能只看最后一轮输出。
- 社会日结按居民、班次和单块农田拆分，单帧累计工作目标3ms，保留原验收门槛 p95≤4ms、单帧≤8ms。存档记录批次游标与市场日结边界，休息跨日或中途读档后继续。
- 收件箱按事件ID索引查重，顺序事件直接追加；事务回滚仅撤销本批新增事件，不复制全部历史。寻路按网格版本共享缓存，作物按实际种植地块更新。

## 28 日经济结果

三组各以42/93/137运行28日，合计252个游戏日；每7日存读档。全部账户与托管核对无负数、日结无遗漏，资金守恒差额始终0，市场食物库存短缺人日为0。以下“未用餐人日”由购买力不足造成，不等于供货不足。

| 组别 | 三种子的未用餐人日 | 居民批次 p95 范围 | 全程每帧居民日结峰值 |
| --- | --- | --- | --- |
| 规则经营 | 14 / 14 / 14 | 1.476～1.508 ms | 5.742 ms |
| 私人 NPC 回放 | 2 / 2 / 2 | 1.528～1.849 ms | 6.445 ms |
| 再加公共协调回放 | 2 / 2 / 2 | 1.666～2.065 ms | 6.499 ms |

批次p95来自各次最后10,000个样本，峰值覆盖全程，包含同一帧多次调用的累计工作；不包含场景初始化和读档重建寻路图。正常帧表现另用图形长测记录。回放源为有合作社、相同风车位置的第二个真实窗口，避免将旧夹具建筑ID失效误算为策略差异。

私人组保留3个真实生产计划，合法销售增加收入，公共组的模型全部选择等待，没有资金支出和干预振荡。这一组初始条件未出现需要公共拨款的紧急缺口；公共食品/维修/活动的正向出资分别由P7/P10/P11验证，不能从“等待”推断所有公共政策都有效。第28日仍有2名角色未能用餐，平衡问题未被抹去。

另跑两条玩家路线各28日、种子42：种植路线通过原地块动作完成24次收获、3次补购种子和16次销售，实际市场净收入629金币；工具损耗导致12次浇水未执行，未强制补耐久。转售路线通过原市场完成14次买入、14次卖出，实际净亏32金币，买卖差价照常生效。两条路线每周存读档，资金对账差额0。玩家出租路线由私人NPC回放实际完成两笔风车加工，玩家余额50,000→50,080，成品归租客。合计308游戏日测试，不等同于全路线人工体验。

可用 `--strategy=farmer` 或 `--strategy=trader` 单独复现；批量脚本会在九组比较后追加这两次运行，结果为 `P12-strategy-{farmer,trader}-42.json`。玩家与市场的金币净流量单独记账，未误记为居民工资或额外赠款。

## 已知限制与结果边界

- 初次扩容只有消费没有足够生产，所有居民后期缺粮；该失败保存在 `P12-economy-before-production.json`。新增真实合作社后，规则组28日无全局食物库存短缺，但后期两名重点NPC可能因收入不足买不起食物。需要继续调校自主就业、技能和生活成本，不通过赠送金币掩盖贫困。
- 真实14日窗口中观察到老李自主加工销售、学者自主出行、阿禾种植决策，以及公共协调者按短缺选择采购或等待。部分生产计划因期限/卖价不满足而失败，后续延长期限、提高加工预算的调整留有记录。
- 私人分工另在36人场景运行P8真实AI流程，双方自主协商后实际配送，跨读档付款一次。工作、调查和活动的不同项目类型另有P8～P11真实闭环；并非每个14日窗口都会自发出现所有类型。
- 当前人物和面板是功能接入，尚未完成TD-01人物美术和TD-07菜单重构。没有宣称完成人工逐一体验所有玩家路线。
- 多地图R1～R4仍未实现；P9地点和P10场外商道不代表可切换地图。天气暂只有降雨、少量作物和咬钩影响，未包含完整季节天气美术。
