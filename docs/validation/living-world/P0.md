# P0 对话交易与真实执行结果验收

日期：2026-09-08。分支：`feature/3d-farm-preview`；基线提交 `9462470`，本报告对应其上的工作区改动。

状态：实现及自动化验收通过；已完成配置中的真实 Provider 与正式 3D 界面的自动交互验证。不是人工鼠标试玩记录。

## 交付

- 原对话面板显示双方物品、金币、有效期及接受／拒绝／还价操作；待处理报价优先展示，旧报价失效后不能成交。
- 3D 对话在动作核验后显示提交结果。流式原始内容留在调试追踪；失败不显示成功，纯交谈明确标注未提交操作。
- 暂停期间可处理对话交易；加工委托延后至恢复时重新检查资产、费用、队列和权限。关闭未完成生成会取消请求；关闭已经回复的对话保留已接收委托。
- 订单通过请求 ID、动作幂等键和建筑实例 ID 串联，保留排队、运行、可领取／已交付、取消记录。执行器的“进行中”在真实交付时转为“完成”。
- 修复两个实测缺陷：JSON 整数被 Godot 解析为浮点数后导致合法交易遭拒；读档重建执行器后丢失 3D 农场连接。
- 服务端对话工具现在允许租用加工；工具说明明确交易 give／receive 的主体以及加工阶段。

打开 NPC 对话后可议价。真实模式不预置交易，需在对话中提出交换或加工意向。测试模式不读取、自动写入正式农场存档；显式保存写入 `tmp/living-world/P0.json`。未提供真实服务参数时不调用模型。

## 失败样本与边界

修复前真实调用确实出现过合法交易被数值类型拒绝、租用工具未在对话模式开放，以及模型混淆交易双方库存、仅口头承诺而未调用工具。前两个是已修复的代码缺陷；后两个保留为模型行为样本。验收脚本允许有限次数的明确追问，仍不调用工具就失败退出，不伪造命令或放宽资产检查。真实模型通过一次不代表每次都会接受同样的提议。

未提交的生成／恢复前待核验响应不作为已成交事项存档；已接受的交易与生产订单持久化。本阶段没有实现自由项目或临时任务恢复，属于 P3／P6。
