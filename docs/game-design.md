# Villa 游戏策划案

## 游戏概述

**名称**：Villa（山谷农庄）
**类型**：休闲经营 + 探索解谜
**视角**：正交俯视角（微缩景观风格）
**平台**：PC（macOS/Windows/Linux）
**引擎**：Godot 4.7
**一句话**：在山谷中经营农场，探索深处的秘密——种植、收获、发现，两个世界互相滋养。

---

## 核心设计理念

### 双循环驱动

```
┌─────────────┐     ┌─────────────┐
│   农庄循环   │◄───►│   探秘循环   │
│             │     │             │
│ 种植→收获   │     │ 探索→收集   │
│ 赚钱→扩建   │     │ 解谜→解锁   │
│ 装饰→美化   │     │ 发现→故事   │
└─────────────┘     └─────────────┘
       │                   │
       ▼                   ▼
  资源/工具 ←────────→ 稀有种子/蓝图
  金币/材料             古代遗物/配方
```

**核心原则**：
- 农庄是"家"，探秘是"冒险"——玩家随时可以在两者间切换
- 探秘获得的稀有物品让农庄更独特（稀有作物、装饰、工具升级）
- 农庄产出的资源支持更深入的探索（更好的装备、照明、食物补给）
- 两个循环互相驱动，但不强制——玩家可以偏重任何一方

## 世界观与故事

### 背景

你来到一个被遗忘的山谷。山谷入口处有一座破败的别墅（Villa），周围是荒废的农田和杂草丛生的道路。山谷深处被浓雾笼罩，似乎隐藏着什么。

你决定留下来，重建这片土地。

### 故事碎片（通过探索逐步解锁）

山谷曾经属于一位**植物学家**，他在这里建立了一个独特的生态花园，培育了来自世界各地的稀有植物。他相信"每一颗种子都藏着一个故事"。

但某天，他消失了。山谷逐渐荒芜，道路被杂草覆盖，深处的花园被迷雾封锁。

玩家通过探索收集到的**日记碎片、种子标本、工具笔记**，逐步拼凑出植物学家的故事：
- 他为什么选择这个山谷？
- 他培育的"终极种子"是什么？
- 他去了哪里？

**结局**：当玩家收集到所有故事碎片并培育出"终极种子"，山谷恢复生机，植物学家的秘密揭晓——他并没有消失，而是化作了山谷的一部分（一棵巨大的古树）。玩家成为了新的守护者。

### 故事节奏

| 阶段 | 解锁内容 | 故事揭示 |
|------|----------|----------|
| 初期 | 别墅附近 | "这里曾经有人生活" |
| 中期 | 山谷中层 | "他是个植物学家，在寻找什么" |
| 后期 | 山谷深处 | "他培育了一种特殊的种子" |
| 终局 | 秘密花园 | "他变成了树，等待下一个守护者" |

## 地图设计

### 区域划分

```
┌─────────────────────────────────────────────┐
│           🌫️ 迷雾峰（后期解锁）               │
│     高山区域，稀有矿物和古代遗迹               │
├─────────────────────────────────────────────┤
│           🌲 深林（中期解锁）                  │
│     密林区域，稀有树种和动物踪迹               │
├─────────────────────────────────────────────┤
│           🏡 山谷农庄（初始区域）              │
│     别墅、农田、道路、溪流                     │
├─────────────────────────────────────────────┤
│           🌊 溪谷入口（初期解锁）              │
│     溪流下游，钓鱼点和湿地植物                 │
└─────────────────────────────────────────────┘
```

### 各区域详情

#### 1. 山谷农庄（初始区域）

**面积**：约 60% 的当前地形
**内容**：
- 别墅（可修复和装饰）
- 农田网格（可开垦种植）
- 溪流（灌溉水源）
- 现有道路系统
- 现有 28 棵树（部分为果树）
- 工具棚（初始工具存放）

**玩法**：种植、建造、装饰、与村民互动

#### 2. 溪谷入口（初期解锁）

**解锁条件**：修复农庄的桥梁（需要 50 木材 + 30 石头）
**内容**：
- 钓鱼点（3-5 个）
- 湿地植物（芦苇、荷花）
- 稀有种子（水生作物）
- 收集品：漂流瓶（含故事碎片）

**玩法**：钓鱼、收集水生植物、发现漂流瓶

#### 3. 深林（中期解锁）

**解锁条件**：获得提灯工具 + 农庄等级达到 3
**内容**：
- 密集树木（需要砍伐开路）
- 稀有树种（可移植到农庄）
- 动物踪迹（鹿、兔子、鸟类）
- 隐藏洞穴（含收集品和谜题）
- 植物学家的旧营地（日记碎片）

**玩法**：探索、砍伐开路、收集稀有树种、解谜

#### 4. 迷雾峰（后期解锁）

**解锁条件**：收集 80% 故事碎片 + 农庄等级达到 5
**内容**：
- 高山地形（需要滑翔伞到达）
- 古代遗迹（石碑、机关谜题）
- 稀有矿物（用于终极工具升级）
- 秘密花园入口（终局区域）

**玩法**：高难度探索、机关解谜、最终故事揭示

## 农庄系统

### 1. 地块网格系统

**网格规格**：
- 在地形上划分 1×1 世界单位的网格
- 每个网格可处于以下状态之一：荒地、农田、建筑、道路、装饰、水域
- 网格受地形高度影响——坡度过大的区域不可开垦

**开垦流程**：
1. 选择荒地网格
2. 消耗工具（锄头）和体力
3. 清除杂草/石头（动画反馈）
4. 变为可种植的农田

**农田状态**：
- 干燥 → 浇水 → 湿润 → 种植 → 生长中 → 成熟 → 收获 → 干燥（循环）

### 2. 种植系统

**作物分类**：

| 类型 | 示例 | 生长天数 | 售价 | 特殊 |
|------|------|----------|------|------|
| 蔬菜 | 番茄、胡萝卜、土豆 | 3-5 | 低 | 基础作物 |
| 水果 | 草莓、蓝莓、西瓜 | 5-8 | 中 | 需要果树/藤架 |
| 花卉 | 向日葵、玫瑰、薰衣草 | 4-6 | 中 | 装饰+售卖 |
| 稀有 | 月光花、星尘果 | 10-14 | 高 | 仅探秘获得种子 |
| 水生 | 荷花、芦苇 | 6-8 | 中 | 仅溪谷区域 |

**生长机制**：
- 每个作物有 3-4 个生长阶段（种子→发芽→成长→成熟）
- 每天检查一次生长（基于游戏内时间）
- 浇水加速生长（+50%速度），不浇水则正常速度
- 季节影响：某些作物只在特定季节生长

**种子获取**：
- 初始：工具棚赠送基础种子包
- 商店购买：用金币购买常见种子
- 探秘获得：稀有种子只能通过探索获得
- 收获留种：收获时有 20% 概率额外获得 1 颗种子

### 3. 建筑系统

**可建造建筑**：

| 建筑 | 功能 | 占地 | 造价 |
|------|------|------|------|
| 谷仓 | 增加库存上限 | 2×2 | 100木材+50石头 |
| 温室 | 无视季节种植 | 3×3 | 200木材+100石头+50玻璃 |
| 风车 | 加工作物（面粉等） | 2×2 | 150木材+80石头 |
| 鸡舍 | 养鸡产蛋 | 2×2 | 80木材+40石头 |
| 蜂箱 | 产蜂蜜，加速附近花卉生长 | 1×1 | 50木材+30花朵 |
| 水井 | 提供灌溉水源 | 1×1 | 60石头+30木材 |
| 工作台 | 制作工具和装饰 | 1×1 | 40木材+20石头 |
| 路灯 | 夜间照明，装饰 | 1×1 | 20木材+10铁 |
| 围栏 | 划分区域，装饰 | 1×1 | 10木材 |

**建造流程**：
1. 选择建筑类型
2. 在网格上预览（绿色=可建造，红色=不可建造）
3. 确认放置，消耗资源
4. 建造动画（可选：即时完成或等待时间）

### 4. 经济系统

**货币**：金币（Gold）

**收入来源**：
- 售卖作物（主要收入）
- 售卖加工品（面粉、果酱、蜂蜜——价值更高）
- 完成订单（NPC 请求特定物品）
- 探索发现（宝箱、稀有物品）

**支出**：
- 购买种子
- 建造/升级建筑
- 购买工具/装备
- 购买装饰物

**订单系统**：
- 每天随机生成 2-3 个订单（NPC 来请求）
- 订单有类型（作物、加工品、收集品）和数量要求
- 完成订单获得金币 + 好感度 + 偶尔稀有奖励
- 订单有 3 天期限，过期不惩罚

### 5. 季节系统

**四季循环**：
- 每季 7 天（游戏内时间）
- 完整循环：28 天

| 季节 | 视觉 | 可种植 | 特殊事件 |
|------|------|--------|----------|
| 春 | 嫩绿、樱花 | 番茄、草莓、向日葵 | 春雨（自动浇水） |
| 夏 | 深绿、阳光 | 西瓜、蓝莓、玫瑰 | 热浪（需多浇水） |
| 秋 | 金黄、红叶 | 胡萝卜、薰衣草 | 丰收节（订单翻倍） |
| 冬 | 白雪、枯枝 | 无（温室除外） | 冬季探索加成 |

**季节影响**：
- 作物：不同季节可种植不同作物
- 视觉：地形颜色、树木外观、天气效果变化
- 探索：冬季某些区域更容易到达（溪流结冰）
- 活动：季节特殊事件和订单

### 6. 村民系统

**NPC 村民**（4-6 个，逐步解锁）：

| 村民 | 角色 | 功能 | 好感度奖励 |
|------|------|------|------------|
| 老李 | 杂货商 | 卖种子和基础材料 | 折扣 |
| 小花 | 花艺师 | 收购花卉，给装饰配方 | 稀有花种 |
| 铁匠张 | 工匠 | 升级工具 | 工具升级折扣 |
| 渔夫阿水 | 渔夫 | 教钓鱼，收购鱼 | 稀有鱼饵 |
| 学者林 | 学者 | 鉴定收集品，讲故事 | 故事碎片提示 |
| 旅行者 | 随机访客 | 带来远方物品 | 稀有种子/蓝图 |

**好感度系统**：
- 每个村民有 0-100 的好感度
- 提升方式：完成订单、送礼、日常对话
- 好感度等级：陌生(0-20)→友好(21-50)→亲密(51-80)→知己(81-100)
- 每个等级解锁不同奖励

**村民行为**：
- 白天在固定位置（商店、工作台）
- 傍晚在村庄散步
- 晚上回家
- 偶尔来访农庄，评论玩家的进展

## 探秘系统

### 1. 探索机制

**迷雾系统**：
- 未探索区域被迷雾覆盖
- 玩家靠近后迷雾消散，揭示区域
- 已探索区域在小地图上显示

**工具依赖**：
- 某些区域需要特定工具才能进入
- 工具通过农庄资源制作或探索发现

**探索工具**：

| 工具 | 功能 | 获取方式 |
|------|------|----------|
| 提灯 | 照亮暗处，进入洞穴 | 工作台制作（20木材+10铁） |
| 滑翔伞 | 从高处滑翔到低处 | 深林宝箱 |
| 绳索 | 跨越悬崖 | 工作台制作（30纤维） |
| 镐 | 开采矿物 | 铁匠张升级 |
| 指南针 | 显示附近收集品 | 学者林赠送 |
| 潜水镜 | 水下探索 | 渔夫阿水赠送 |

### 2. 收集品系统

**收集品分类**：

| 类别 | 数量 | 获取方式 | 用途 |
|------|------|----------|------|
| 日记碎片 | 12 | 探索发现 | 解锁故事 |
| 稀有种子 | 15 | 探索宝箱/采集 | 种植稀有作物 |
| 化石 | 8 | 矿物区域挖掘 | 学者林鉴定→金币 |
| 古代遗物 | 6 | 遗迹解谜 | 解锁终极工具 |
| 植物标本 | 20 | 采集稀有植物 | 图鉴+装饰 |
| 动物足迹 | 10 | 深林发现 | 图鉴+成就 |
| 漂流瓶 | 5 | 溪谷钓鱼 | 故事碎片 |
| 矿物 | 12 | 迷雾峰开采 | 工具升级材料 |

**图鉴系统**：
- 每个收集品类别有独立图鉴
- 收集后显示物品信息和描述
- 完成图鉴类别获得奖励（装饰、成就）

### 3. 解谜系统

**谜题类型**：

#### a) 环境谜题
- **推石头**：将石头推到指定位置激活机关
- **连接道路**：调整道路碎片，连接起点和终点
- **光线反射**：调整镜子角度，让光线到达目标

#### b) 收集谜题
- **献祭台**：放置特定物品组合，解锁新区域
- **植物配对**：种植特定植物组合，激活隐藏通道

#### c) 时序谜题
- **季节机关**：某些机关只在特定季节可激活
- **时间机关**：某些区域只在特定时间（白天/夜晚）开放

#### d) 遗迹谜题（后期）
- **石碑密码**：解读石碑上的符号，输入正确密码
- **古代机关**：多步骤的复杂机关，需要多个工具配合

**谜题设计原则**：
- 每个谜题有明确的视觉反馈
- 难度渐进，前期简单教学，后期复杂组合
- 谜题奖励与难度匹配
- 可选谜题——不强制完成所有谜题

### 4. 探索区域详情

#### 溪谷入口

**环境**：溪流、湿地、芦苇丛
**收集品**：漂流瓶(3)、水生植物种子(5)、鱼类图鉴
**谜题**：
- 修复水车（连接道路谜题）→ 解锁下游区域
- 钓鱼收集特定鱼类 → 渔夫阿水的任务

**特殊机制**：
- 钓鱼小游戏（简单的时机判断）
- 水位变化（雨季水位上升，露出新区域）

#### 深林

**环境**：密集树木、阴暗、动物踪迹
**收集品**：稀有树种(5)、植物标本(8)、日记碎片(5)、动物足迹(6)
**谜题**：
- 砍伐特定树木序列，开辟道路
- 跟随动物足迹，找到隐藏洞穴
- 植物学家的旧营地（日记碎片+简单机关）

**特殊机制**：
- 需要提灯照明（否则视野受限）
- 树木会阻挡道路，需要砍伐
- 动物会逃跑，需要悄悄接近

#### 迷雾峰

**环境**：高山、悬崖、古代遗迹
**收集品**：矿物(12)、古代遗物(6)、日记碎片(4)、植物标本(4)
**谜题**：
- 石碑密码（需要解读多个石碑）
- 光线反射（调整镜子，照亮遗迹入口）
- 献祭台（放置所有古代遗物，解锁秘密花园）

**特殊机制**：
- 需要滑翔伞跨越悬崖
- 需要镐开采矿物
- 高海拔区域，体力消耗增加

#### 秘密花园（终局）

**环境**：美丽的花园，中央有一棵巨大的古树
**收集品**：终极种子、最后的日记碎片
**谜题**：
- 最终谜题：种植终极种子，需要所有故事碎片和古代遗物

**结局**：
- 种植终极种子后，古树发光，植物学家的灵魂出现
- 讲述完整故事
- 山谷恢复生机，所有区域解锁特殊视觉效果
- 游戏进入"自由模式"——继续经营和探索，无限制

## 玩家系统

### 1. 角色属性

**体力（Stamina）**：
- 上限：100
- 消耗：种植(5)、浇水(3)、砍伐(10)、探索(2/秒在特殊区域)
- 恢复：时间自然恢复(1/秒)、食物(即时恢复)、睡觉(完全恢复)

**等级（Level）**：
- 通过经验值提升
- 经验来源：种植收获、完成订单、探索发现、解谜
- 每级解锁：新建筑、新工具、新区域

**等级解锁表**：

| 等级 | 解锁内容 |
|------|----------|
| 1 | 基础工具、农田开垦 |
| 2 | 鸡舍、围栏 |
| 3 | 溪谷入口、提灯 |
| 4 | 温室、风车 |
| 5 | 深林、工作台 |
| 6 | 水井、蜂箱 |
| 7 | 迷雾峰、滑翔伞 |
| 8 | 终极工具升级 |
| 9 | 秘密花园 |
| 10 | 全部解锁 |

### 2. 操作方式

| 行为 | 输入 |
|------|------|
| 移动 | WASD / 方向键 |
| 跳跃 | Space |
| 交互/使用工具 | 鼠标左键 |
| 切换工具 | 数字键 1-6 / 滚轮 |
| 打开背包 | Tab / I |
| 打开地图 | M |
| 镜头旋转 | Q/E / 中键拖动 |
| 镜头缩放 | 鼠标滚轮 |
| 奔跑 | Shift（消耗体力） |

### 3. 背包系统

**背包结构**：
- 初始：20 格
- 升级：谷仓增加上限（+10/级，最多 50 格）
- 分类：工具、种子、作物、材料、收集品

## 美术方向

### 视觉风格

**微缩景观 + 手绘感**：
- 正交视角天然适合"微缩模型"风格
- 树木使用 Billboard 手绘风格（已有）
- 地形使用手绘纹理
- 建筑使用简洁的几何体 + 手绘纹理
- 色彩明亮、饱和，偏暖色调

### 参考风格
- 《Stardew Valley》的像素温馨感
- 《Animal Crossing》的可爱微缩感
- 《A Short Hike》的自然探索感

### 需要的美术资源

**地形**：
- 草地纹理（已有）
- 泥土纹理（农田）
- 石头纹理
- 水面效果
- 雪地纹理（冬季）

**作物**：
- 每种作物 3-4 个生长阶段的 Sprite
- 约 15 种作物 × 4 阶段 = 60 个 Sprite

**建筑**：
- 每种建筑的 3D Mesh 或 Sprite

**收集品**：
- 每种收集品的图标/Sprite
- 约 80 种收集品

**UI**：
- HUD 元素
- 背包界面
- 建造界面
- 地图界面
- 对话界面

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 村民AI复杂度高 | 开发延期 | 简化行为树，使用状态机 |
| 地形网格性能 | 帧率下降 | 使用 LOD，只渲染可见网格 |
| 内容量过大 | 开发周期长 | Phase 1-3 先做最小可玩版本 |
| 双循环平衡 | 某一玩法被忽视 | 设计强制交叉点（稀有种子只能探索获得） |
| 故事碎片节奏 | 玩家失去兴趣 | 每个碎片都有实质奖励，不只是文本 |
