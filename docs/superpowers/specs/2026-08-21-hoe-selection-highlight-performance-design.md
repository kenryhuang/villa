# 锄头选择与地块阴影性能修复设计

## 目标

修复种植模式下选择锄头时的数秒卡顿，并恢复鼠标悬停地面时的单格放置阴影：可锄地块显示绿色，不可锄地块显示红色。

## 已确认交互

- 游戏启动时仍保持未选择模式。
- 按 `P` 只进入种植模式并显示六个快捷项，不自动选择工具。
- 明确点击锄头或按数字 `1` 后立即完成工具选择。
- 鼠标移到地面后显示一个跟随网格的地块阴影。
- 可锄地块使用现有绿色反馈，不可锄地块使用现有红色反馈。
- 鼠标停留在同一格时，阴影保持稳定，不产生持续资源重建。

## 根因

### 工具选择被错误发布为库存变化

`ToolSystem.switch_tool()` 在每次工具切换时发送 `EventBus.item_added(tool_id, 0)`。工具选择并没有改变库存，但该事件会同步通知库存、服务、生产、市场、订单、合同等多个 UI。部分接收方会重建服务卡片或生产快照，因此一次简单的锄头选择会触发与操作无关的同步刷新。

控制器已经通过 `selection_changed` 和 `palette_changed` 更新工具名称与选中状态；工具耐久也有独立的 `tool_durability_changed` 事件。因此工具切换不需要伪造库存事件。

### 地块高亮每帧重建渲染资源

选择锄头后，`PlayerActionController._process()` 每帧调用 `GridSystem.highlight_cell()`。当前实现每次调用都会创建新的 `SurfaceTool`、提交新的 Mesh，并创建新的 `StandardMaterial3D`，即使鼠标仍在同一格且颜色没有变化。这会造成主线程和渲染资源分配压力，妨碍阴影及时显示。

## 设计

### 1. 工具切换使用正确的事件语义

`ToolSystem.switch_tool()` 只更新 `current_tool`，不再发送零数量的 `item_added`。自动装备工具的路径同样不得用零数量库存事件表达工具变化。

本次不新增全局工具选择事件，因为现有消费者已经由 `PlayerActionController.selection_changed` 和 `palette_changed` 驱动。真实库存增减仍由库存事务发送 `item_added` 或 `item_removed`；耐久变化仍发送 `tool_durability_changed`。

### 2. 地块高亮资源复用

`GridSystem.highlight_cell(gx, gz, color)` 保持现有公开接口和返回值，但改为幂等更新：

1. 校验高亮节点、地形和网格边界。
2. 若目标格与当前 Mesh 对应的格子不同，才重新采样四个地形角点并生成 Mesh。
3. 复用高亮节点已有的 `StandardMaterial3D`；只有材质不存在时才创建。
4. 将颜色规范化到现有最大透明度，并仅在颜色变化时更新材质颜色。
5. 无论资源是否更新，都确保元数据正确且节点可见。

`clear_highlights()` 只隐藏节点，不丢弃缓存。鼠标重新回到原格时可以直接恢复可见；若格子或颜色已变化，再执行相应更新。

### 3. 阴影显示规则保持不变

控制器继续使用现有规则：

- 只有种植模式下已选择支持地块操作的槽位才显示阴影。
- 锄头悬停可耕格为绿色，否则为红色。
- 超出玩家操作距离时为红色。
- 鼠标位于 UI 上、无有效地面命中或取消选择时隐藏阴影。
- 斧头和镐仍使用目标物反馈，不显示地块阴影。

## 数据与事件流

```text
点击锄头 / 数字 1
  -> PlayerActionController.select_mode_slot(0)
  -> ToolSystem.current_tool = HOE
  -> selection_changed / palette_changed 更新 HUD
  -> 不发送 item_added

鼠标悬停地面
  -> 控制器解析目标格与绿/红状态
  -> GridSystem.highlight_cell(gx, gz, color)
     -> 同格：复用 Mesh
     -> 同材质：复用 StandardMaterial3D
     -> 必要时更新几何或颜色
  -> 阴影可见
```

## 错误与边界处理

- 越界格、缺失地形或缺失高亮节点继续返回 `false` 并隐藏阴影。
- 已缓存格子在地形静态不变的前提下复用 Mesh；本项目运行时不会修改地形高度。
- 切换到 UI、建造模式或无选择状态时继续隐藏阴影。
- 不改变真实物品增加、移除和工具耐久事件。

## 测试策略

采用测试先行：

- `ToolSystem.switch_tool()` 改变当前工具，但不发送 `item_added`。
- 自动装备路径不发送零数量库存事件。
- 同一格、同一颜色重复高亮时 Mesh 与材质对象保持相同。
- 同一格改变有效性颜色时复用 Mesh 和材质，只更新颜色。
- 换到另一格时阴影元数据与几何位置正确。
- 清除后重新高亮同一格会恢复可见。
- 控制器选择锄头后允许地块阴影，并保留现有绿/红判定。
- 真实主场景中进入 P 模式、选择锄头、移动指针后高亮节点可见且对齐目标格。

定向测试通过后运行工具系统、网格系统、玩家操作控制器和本次 action-mode 回归套件。全集成套件的既有经济/存档基线失败单独记录。

## 非目标

- 不重做所有地块或建筑预览架构。
- 不改变锄地、浇水、播种的业务规则和体力消耗。
- 不改变 P/B 模式交互。
- 不优化与工具选择无关的经济 UI。
