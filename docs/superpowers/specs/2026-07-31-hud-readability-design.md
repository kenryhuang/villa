# HUD 图标与状态栏可读性设计

日期：2026-07-31  
状态：设计已确认，待实施

## 1. 背景与根因

主游戏画布已经扩大为 `3000 × 2000`，但 HUD 仍沿用较小的默认尺寸：

- 顶部状态文字使用 Godot 默认字号，约 `16px`。
- 顶部 `TopBar` 是没有背景的 `HBoxContainer`，文字直接叠在地形、树木和道路上。
- 底部快捷按钮只有 `58px` 高。
- 图标与两行按钮文字共用 Godot `Button` 的原生横向内容布局，图像被文字进一步压缩。

因此即使源图是清晰的 `256 × 256` PNG，游戏内的实际显示区域仍然很小；顶部浅色或深色地形还会持续改变文字对比度。

## 2. 目标

- 底部工具、种子和建筑图标在当前 `3000 × 2000` 画布中可快速辨认。
- 顶部金币、等级、季节、日期和时间不再与世界背景混在一起。
- 延续当前暖色手绘 2.5D 风格，不改成现代纯色仪表盘。
- 保持种植六项、建造九项以及模式按钮单行完整显示。
- 保留数字键、鼠标点击、选中状态、资源不足状态和 Tooltip 行为。
- 不修改地图尺寸、相机、世界建模或玩法数据。

## 3. 已选视觉方向

采用视觉对比稿中的方案 B“平衡易读”：

- 米白色高对比文字。
- 深橄榄色高不透明底板。
- 暖金色细边框。
- 明显但不过度占屏的图标和字号。
- 轻微阴影或深色描边，使信息在任何地形上都保持可读。

不采用：

- 方案 A：改善幅度有限，在大画布上仍可能偏小。
- 方案 C：最醒目，但顶部和底部 HUD 占屏面积过大。

## 4. 顶部状态栏

### 4.1 节点结构

将当前没有背景的 `TopBar (HBoxContainer)` 调整为：

```text
TopBar (PanelContainer)
└── StatusRow (HBoxContainer)
    ├── StaminaBar
    ├── GoldLabel
    ├── LevelLabel
    ├── ExpBar
    ├── SeasonLabel
    └── TimeLabel
```

`TopBar` 保留现有语义名称，脚本和运行时场景测试更新为新的子路径。

### 4.2 视觉规格

- 面板背景：深橄榄色，透明度不低于 `0.86`。
- 边框：暖金色，`2px`。
- 圆角：`12px`。
- 内容边距：水平 `18px`，垂直 `12px`。
- 状态文字字号：`32px`。
- 文字颜色：暖米白色。
- 深色描边：`4px`。
- 状态项间距：`18px`。
- 体力条最小尺寸：`260 × 44px`。
- 经验条最小尺寸：`220 × 44px`。

低体力仍使用红色填充；正常体力仍使用绿色填充。文字颜色不随世界背景或资源状态改变。

## 5. 底部操作按钮

### 5.1 专用按钮组件

新增一个可复用的操作按钮场景：

```text
ActionPaletteButton (Button)
├── Icon (TextureRect)
├── ShortcutLabel (Label)
└── NameLabel (Label)
```

HUD 仍动态创建六个或九个按钮，但不再把图标和两行文字塞进原生 `Button.text` 布局。子控件使用 `MOUSE_FILTER_IGNORE`，点击仍由根 `Button` 接收。

组件公开最小接口：

```gdscript
func configure(
    shortcut: int,
    display_name: String,
    texture: Texture2D
) -> void

func set_selected(selected: bool) -> void
func set_available(available: bool) -> void
```

### 5.2 尺寸与层级

- 按钮最小尺寸：`112 × 116px`。
- 图标显示区域：`84 × 84px`。
- 图标保持宽高比并居中，不裁切、不拉伸。
- 快捷键角标：按钮左上角，`26px` 字号，金色小底板。
- 名称标签：按钮底部居中，`22px` 米白字，`3px` 深色描边。
- 种子数量显示为名称的一部分，例如“种子 ×2”；完整名称仍保留在 Tooltip。
- 普通按钮使用深橄榄半透明背景和低亮金色边框。
- Hover 提高边框亮度。
- 选中状态使用明亮金色边框和轻微暖色底光。
- 资源不足只降低图标饱和度/亮度，不降低文字和快捷键角标的清晰度。

九个建造按钮、模式按钮和间距的组合最小宽度不得超过 `1280px`，因此在当前画布和常用窗口尺寸下仍保持单行。

### 5.3 模式按钮

模式按钮同步放大到与操作按钮相同高度，使用 `84px` 图像区域和底部模式名称。悬停菜单行为、`P/B` 快捷键和模式记忆不变。

## 6. BottomBar 布局

- `BottomBar` 宽度扩大以容纳新按钮，继续锚定窗口底部中心。
- 底部偏移增加，避免更高的按钮超出窗口。
- 当前动作说明 `ToolLabel` 使用 `28px` 米白字和深色描边。
- 模式菜单按钮字号提高到 `24px`，菜单尺寸随内容扩大。
- HUD 控件继续拦截鼠标，世界点击逻辑不变。

## 7. 数据流与兼容性

`PlayerActionController` 仍是模式和选择的唯一权威状态：

```text
控制器模式/选择信号
        ↓
VillaHud.rebuild_action_palette()
        ↓
ActionPaletteButton.configure()
        ↓
按钮 pressed
        ↓
PlayerActionController.select_mode_slot()
```

本次只改变显示组件和布局：

- 不改变模式 ID、按钮顺序或快捷键。
- 不改变库存数量、建筑造价或资源判断。
- 不改变建筑预览、种植交互或连续建造。
- 图标加载失败时按钮仍显示快捷键和名称，并保持可点击。

## 8. 测试与视觉验收

### 8.1 自动化测试

- `TopBar` 是带样式的 `PanelContainer`。
- 四个状态文字字号不低于 `32px`，描边不低于 `4px`。
- 体力条和经验条高度不低于 `44px`。
- 种植模式生成六个专用按钮。
- 建造模式生成九个专用按钮。
- 每个按钮图标区域至少为 `84 × 84px`。
- 快捷键和名称标签存在且字号符合规格。
- 鼠标点击继续调用统一选择接口。
- 选中与资源不足状态不会降低文字透明度。
- 完整建造操作栏最小宽度不超过 `1280px`。

### 8.2 运行验收

- 在主场景中，锄头、浇水壶、斧头、镐、鱼竿、种子和建筑图像无需靠近屏幕即可辨认。
- 左上信息经过草地、道路、树冠和亮色地形时仍清晰。
- 最大化和普通窗口下 HUD 不被裁切。
- 模式菜单从放大的模式按钮上方向上展开。
- Godot 编辑器解析、主场景集成测试和实际运行无新增错误。
