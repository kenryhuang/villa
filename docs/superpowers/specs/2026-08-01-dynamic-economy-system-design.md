# Villa 动态经济系统设计

**日期：** 2026-08-01  
**状态：** 已确认  
**范围：** 材料、种植与建筑生产、市集、NPC 经济、合成、进程和平衡  

## 1. 目标

建立一个由玩家与 NPC 共同参与、能够自行运转的区域经济。玩家通过采集、种植、自动生产、加工和交易扩大经营规模；NPC 则根据自己的库存、资金、生产能力和生活需求参与市场，最终共同形成可观察、可利用但不能轻易操纵的动态价格。

系统采用以下已确认方向：

- 供需波动型经济，而非固定价格商店。
- 混合生产：生产建筑自动运转并暂存产物，玩家定期收取；水车、温室等建筑提供持续范围效果。
- 世界供需与玩家交易共同影响价格。
- 混合 NPC 模拟：重要 NPC 使用真实库存和资金，普通居民使用后台群体需求。
- 日结供需账本，而非实时订单簿。

## 2. 当前基础与需要调整的部分

当前项目已经具备静态物品价格、种子和材料购买、随机每日订单、库存、季节、作物成长以及建筑数据框架。当前实际注册的作物为谷物、番茄、胡萝卜和土豆；蜂箱、鸡舍、风车、温室、水井等建筑已有描述和效果类型，但多数尚未形成真实生产链。

经济落地时需要一并解决以下结构问题：

- `GameState` 与 `EconomySystem` 当前分别保存金币，必须合并成一个权威来源。由于 HUD 和存档已经读取 `GameState.gold`，设计上由 `GameState` 持有玩家金币，`EconomySystem` 只负责交易和市场结算。
- 当前商店库存无限、价格固定，只支持购买种子和材料，需要迁移到有限库存的市集模型。
- 当前订单从作物和材料中随机抽取，后续应由 NPC 的真实短缺、节日或建设行为产生。
- 当前“铁”应拆为铁矿与铁锭；玻璃保留为加工材料，并补充沙子与燃料来源。
- 当前新游戏给予大量建材属于调试配置，正式经济启用时需要缩减并同步重算建筑成本。

本设计不要求第一版立刻实现所有作物、NPC 职业和高级商品。数据结构必须能够承载完整方案，功能按进程分阶段上线。

## 3. 核心经济架构

经济分为实体经济与背景经济两层。

### 3.1 实体经济

玩家与重要 NPC 拥有：

- 金币；
- 真实库存；
- 生产建筑和生产队列；
- 每日生活需求与生产需求；
- 安全库存目标；
- 可提交到市集的购买或出售意向；
- 经营方向、升级意愿和关系状态。

重要 NPC 示例：木匠、铁匠、面包师、农户和商队。交付给重要 NPC 的订单物品会进入该 NPC 的库存，并可被后续生产真实消耗。

### 3.2 背景经济

普通居民不逐个保存背包与金币，而是按群体产生每日供需：

- 居民消费基础食品、燃料和日用品；
- 建筑工人消费木板、石砖和金属；
- 工匠消费加工材料；
- 游客和富裕居民消费甜点、花束、家具和珠宝；
- 节日、天气和地区事件改变特定群体的需求。

### 3.3 每日数据流

每个游戏日按以下顺序结算：

```text
农场与生产建筑推进
→ NPC 生活和生产消耗
→ 玩家与 NPC 的市集交易写入账本
→ 背景居民供需进入账本
→ 结算市场库存和 NPC 库存
→ 计算并平滑次日价格
→ 生成订单、紧缺提示和商队计划
```

当前一个游戏日为 300 秒，市场基础价格每日更新一次，足够让玩家观察并作出选择。玩家当天的大宗交易通过成交滑点即时反映影响，并进入次日供需压力，不触发全量 NPC 重算。

## 4. 材料体系

### 4.1 材料分层

| 层级 | 材料 | 主要来源 | 主要用途 |
|---|---|---|---|
| 基础资源 | 木材、石材、纤维、黏土、沙子 | 砍树、采石、割草、河岸采集 | 初级建筑与加工 |
| 工业资源 | 煤、铜矿、铁矿 | 矿洞、矿场、商队 | 冶炼、工具、机械 |
| 稀有资源 | 银矿、金矿、水晶 | 深层矿洞、事件、商队 | 高级设备和高价值商品 |
| 加工材料 | 木板、石砖、砖块、玻璃、绳索、布料、金属锭 | 对应生产建筑 | 中高级建筑与合成 |

### 4.2 获取路径

- 木材来自砍树；树木缓慢再生，后期伐木场提供稳定产量。
- 石材来自地图石块和采石点，后期采石场自动生产。
- 纤维来自杂草和亚麻等植物，可加工为绳索和布料。
- 黏土来自河岸、湿地或锄地时的少量副产物。
- 沙子来自河滩和水边采集点。
- 煤既可在矿洞获得，也可用木材烧制木炭替代。
- 铜矿主要分布于浅层矿洞；铁矿位于中层；银矿、金矿和水晶主要位于深层。

每种关键材料至少有三条获得路径：玩家亲自采集、生产建筑自动获取、市集购买。商队是连续短缺时的安全阀，但进口价高于正常本地价格，稀有材料也不会无限补货。

### 4.3 基础加工链

```text
木材 → 木板／木炭
石材 → 石砖
黏土＋煤 → 砖块
沙子＋煤 → 玻璃
纤维 → 绳索 → 布料
铜矿＋煤 → 铜锭
铁矿＋煤 → 铁锭
铁锭＋煤 → 钢材
```

对应设施为工作台、石窑、熔炉和纺织机。伐木场、采石场和矿场负责自动资源产出，但需要建造成本、输出容量以及适度维护。

## 5. 种植、水果与生产建筑

### 5.1 作物设计

当前每季为 7 天，因此常规作物生长周期控制在 2～5 天，保证一个季节内至少完成一次收获。

| 作物 | 季节 | 生长方式 | 经济定位 |
|---|---|---|---|
| 谷物 | 春、夏、秋 | 3 天，收获 2～4 | 面粉、饲料、基础食品 |
| 胡萝卜 | 春、秋 | 3 天，收获 2～3 | 快速回款、腌菜 |
| 土豆 | 春、秋 | 4 天，收获 3～5 | 稳定高产、料理 |
| 番茄 | 春、夏 | 4 天成熟，之后每 2 天再生 | 酱料、料理 |
| 草莓 | 春 | 4 天成熟，之后再生 | 果酱、甜点 |
| 蓝莓 | 夏 | 5 天成熟，之后再生 | 果酱、果汁 |
| 西瓜 | 夏 | 5 天，收获 1～2 | 高价鲜果、果汁 |
| 向日葵 | 夏、秋 | 4 天，收获 2～3 | 食用油、蜂箱增益 |
| 薰衣草 | 夏、秋 | 4 天，收获 2～3 | 香料、香包、蜂箱增益 |
| 南瓜 | 秋 | 5 天，收获 1～2 | 秋季高需求食品 |
| 玫瑰 | 春、夏 | 4 天，收获 2～3 | 花束、香水、蜂箱增益 |

换季时不适宜作物停止生长但不直接枯死；重新进入适宜季节或纳入温室后继续生长。

水果以果树和温室果株为主：苹果树秋季结果，桃树夏季结果，葡萄架在夏秋结果，柠檬树主要在温室培育。温室中的草莓和蓝莓可全年种植。果树投入高、成熟慢，但无需每季重种。

### 5.2 建筑产出与效果

| 建筑 | 输入 | 产出或效果 | 基础节奏 |
|---|---|---|---|
| 蜂箱 | 周围花卉 | 蜂蜜、少量蜂蜡 | 每 2 天约 1 份 |
| 鸡舍 | 谷物饲料 | 鸡蛋，偶尔羽毛 | 每日结算 |
| 水车 | 流动水域 | 自动灌溉范围内农田 | 每日成长前触发 |
| 温室 | 种子、水 | 全季节作物和温室水果 | 玩家种植，建筑提供环境 |
| 风车 | 谷物 | 面粉、动物饲料、食用油 | 自动加工 |
| 工作台 | 木材、纤维、金属 | 木板、绳索、零件、工具 | 配方加工 |
| 石窑 | 石材、黏土、木材 | 石砖、砖块、木炭 | 自动加工 |
| 熔炉 | 矿石、煤、沙子 | 金属锭、钢材、玻璃 | 自动加工 |
| 食品工坊 | 作物、蜂蜜、容器 | 果酱、腌菜、酱料、果汁 | 自动加工 |
| 谷仓 | 无 | 扩大库存、集中收取 | 被动功能 |

蜂箱从附近成熟花卉获得有上限的产量加成。水车必须建在流动水域旁，基础覆盖半径约 4 格，后期可通过灌溉渠扩展。温室提供约 8～12 个种植格，可无视季节并降低浇水负担；连接水车后自动浇灌。

### 5.3 自动生产与收取

- 建筑按游戏时间或每日结算自动推进。
- 默认暂存约 3 天产物，满仓后暂停，不丢失产物，也不继续消耗输入。
- 玩家在建筑旁一键收取。
- 谷仓升级后可集中收取一定范围内的生产建筑。
- 输入在生产开始时扣除；输出容量必须提前验证。
- 存档记录配方、批次数量、剩余时间和暂存产物。

## 6. 市集与动态价格

### 6.1 市集商品信息

每件商品显示玩家买入价、玩家卖出价、当前库存等级、昨日涨跌、最近 7 天走势、需求标签和本次交易预计金额。商品按原材料、农产品、加工材料、食品与手工品、稀有品分类。

市集不是无限商店：玩家出售会增加库存，玩家和 NPC 购买会减少库存；库存为零时必须等待供应或进口。

### 6.2 NPC 决策

重要 NPC 每日按以下优先级行动：

```text
生活必需品
→ 生产原料
→ 执行生产
→ 补足安全库存
→ 出售多余产品
→ 盈利充足时升级或转产
```

NPC 会在原料便宜时适度储备，也可能因缺钱缩小生产。连续高利润的商品会吸引相关 NPC 增产，从而使超额利润逐渐回落。

### 6.3 价格模型

```text
实际价格
= 基础价格
× 库存系数
× 当日供需系数
× 季节系数
× 事件系数
```

建议边界：

- 库存系数：0.70～1.60；
- 季节系数：0.85～1.25；
- 事件系数：0.80～1.50；
- 最终价格：基础价的 50%～250%；
- 单日价格变化：最多 ±15%。

价格每日逐步靠近目标值。基础种子和工具使用更窄的波动范围；鲜果、花卉、加工品可中高幅波动；稀有品波动最大但成交量最低。

### 6.4 买卖差价和滑点

- 玩家买入价约为市场中间价的 110%。
- 玩家卖出价约为中间价的 90%。
- 稀有品和奢侈品可扩大到约 15% 的单边差价。
- 每件商品设有每日流动量；交易越接近或超过流动量，后续单位的成交价越不利。
- 当日交易量进入次日供需账本，玩家无法在同一天反复买卖获利。

### 6.5 商队与缺货保护

基础材料连续缺货 2～3 天后，商队少量高价补货。基础种子和继续经营所需的关键工具不允许永久断货。稀有材料不会无限进口。

### 6.6 订单与合同

- 日常委托：少量、1～2 天期限，溢价 15%～30%。
- 紧急订单：由真实短缺或事件产生，溢价 40%～60%。
- 长期合同：连续数天定量供货，价格稳定，违约影响关系。
- 节日订单：集中需求花卉、食品或装饰品。
- 建设订单：NPC 扩建时需求木板、砖块、玻璃和金属件。

订单交付物进入对应 NPC 的库存，不凭空销毁。普通市售与订单构成“高流动低利润”和“有限量高利润”两种销售渠道。

## 7. 合成与产品价值阶梯

### 7.1 价值定位

| 阶段 | 示例 | 目标特征 |
|---|---|---|
| 原材料 | 木材、矿石、作物 | 流动量大、利润低 |
| 初加工品 | 木板、面粉、金属锭 | 稳定需求，价值增加 20%～40% |
| 成品 | 果酱、工具、家具 | 价值增加 40%～100%，需求有限 |
| 奢侈品 | 香水、珠宝、高级甜点 | 高单价、低流动量 |

### 7.2 代表性配方

| 工作站 | 输入 | 输出 |
|---|---|---|
| 工作台 | 木材×2 | 木板×1 |
| 工作台 | 纤维×3 | 绳索×1 |
| 石窑 | 木材×3 | 木炭×1 |
| 石窑 | 石材×2 | 石砖×1 |
| 石窑 | 黏土×2＋煤×1 | 砖块×2 |
| 熔炉 | 沙子×2＋煤×1 | 玻璃×1 |
| 熔炉 | 铜矿×2＋煤×1 | 铜锭×1 |
| 熔炉 | 铁矿×2＋煤×1 | 铁锭×1 |
| 熔炉 | 铁锭×2＋煤×2 | 钢材×1 |
| 纺织机 | 纤维×4 | 布料×1 |
| 风车 | 谷物×2 | 面粉×1 |
| 风车 | 谷物×1 | 饲料×2 |
| 风车 | 向日葵×3 | 食用油×1 |
| 食品工坊 | 水果×2＋蜂蜜×1＋玻璃罐×1 | 果酱×1 |
| 食品工坊 | 蔬菜×3＋盐×1＋玻璃罐×1 | 腌菜×1 |
| 食品工坊 | 番茄×3＋玻璃罐×1 | 番茄酱×1 |
| 食品工坊 | 水果×3＋玻璃瓶×1 | 果汁×1 |
| 厨房 | 面粉×2＋鸡蛋×1 | 面包×2 |

盐在前期由杂货商或沿海商人稳定供应，后期可扩展盐田。玻璃罐和玻璃瓶作为玻璃的下游材料，为玻璃提供持续消耗出口。

手工产品包括木箱、家具、农具、机械零件、灯具、香包、蜡烛、香水、花束和珠宝。其需求分别由工匠、居民、游客、节日和奢侈品商人产生。

### 7.3 加工时间与利润信息

- 基础材料加工约 2～6 个游戏小时。
- 食品与普通成品约 6～12 小时。
- 家具、工具和奢侈品约 1～2 天。
- 建筑默认提供 2 个队列，升级增加队列、速度或产量，不直接永久提高售价。
- 配方界面显示当前材料、加工时间、燃料、按当前行情计算的投入价值、预计卖价和预计毛利。

初加工品目标基础价值为投入的 1.2～1.4 倍，日常食品为 1.4～1.7 倍，工具与家具为 1.6～2.0 倍，奢侈品可超过 2 倍但流动量很低。实际利润受当天原料与成品价格影响，加工不保证必赚。

## 8. 经营进程与解锁

### 8.1 开局阶段

第一个季节以采集、基础种植和普通订单为主，可使用工作台、石窑和蜂箱。目标是在季末前建立第一条简单加工链。

正式经济上线后，新游戏只提供基础工具、约 10～15 份谷物种子、少量木材石材纤维和足够购买一批种子的金币。初始物资应允许建造工作台或石窑，但不能直接建造温室和风车。

### 8.2 中期阶段

第二至第四个季节解锁风车、鸡舍、水车、熔炉、食品工坊和果树。NPC 开始扩建并与玩家竞争原料，也提供长期合同。谷仓和自动灌溉用于降低重复劳动。

### 8.3 后期阶段

解锁温室、深层矿产、珠宝、香水和高级料理。商队、节日和大型建设项目提供周期性需求，玩家可以经营多条自动生产线，NPC 也会投资、转产和竞争。

### 8.4 收入目标

- 开局每日净收入约 40～80 金币。
- 中期每日净收入约 150～300 金币。
- 后期每日净收入约 500～1000 金币。
- 第一座加工建筑应在第一个季节内可完成。
- 水车或鸡舍约需 1～2 个季节积累。
- 温室是中后期目标。
- 五条主要产业路线的单位时间利润差异尽量控制在 20% 左右。

上述目标是平衡基准，不是硬性每日保底。建筑成本、采集产量、作物产量和售价必须作为一组联动调整。

## 9. 经济来源、消耗与防套利

金币主要由市集销售、订单、合同、节日、商队出口和后期服务建筑产生；主要消耗为种子、饲料、燃料、盐、材料采购、蓝图、升级、维修、NPC 服务、装饰和土地扩张。

材料通过建筑、设备维护、燃料、饲料、容器和生产配方持续消耗，避免长期只增不减。

防套利规则：

- 市集存在买卖差价和大宗交易滑点；
- 加工占用时间、燃料和设备容量；
- 成品有有限流动量，大量出售会压价；
- NPC 会进入长期高利润行业，增加供应；
- 高级配方受建筑、关系或经营进程限制；
- 读档不能刷新价格、订单或 NPC 决策结果。

## 10. 数据模型与组件职责

建议将经济数据拆为以下职责，避免继续把全部逻辑堆入静态 `GameData`：

- `ItemDefinition`：物品分类、基础价格、堆叠、波动等级和流动量。
- `RecipeDefinition`：输入、输出、工作站、时间、燃料和解锁条件。
- `ProducerState`：生产队列、剩余时间、输入状态和输出暂存。
- `MarketState`：每件商品库存、中间价、当日供需、流动量和 7 日历史。
- `NpcEconomyState`：重要 NPC 的金币、库存、安全库存、生产能力和计划。
- `PopulationDemandProfile`：背景群体的基础消费和事件修正。
- `MarketOrder`：买卖方向、商品、数量、价格或市价标志、来源和有效期。
- `Contract`：委托方、交付物、数量、期限、奖励和履约状态。

组件边界：

- `GameState`：玩家金币的唯一权威来源。
- `InventorySystem`：玩家物品的原子增减与容量验证。
- `EconomySystem`：交易校验、成交、订单、日结和对 `GameState` 的金币操作。
- `MarketSystem`：库存、供需账本、价格计算、滑点和历史。
- `NpcEconomySystem`：重要 NPC 决策以及背景群体需求生成。
- `ProductionSystem`：通用生产队列和建筑暂存。
- `GameData` 或独立数据库：只保存静态定义，不保存运行时市场状态。

所有涉及金币和物品的操作都应具备事务语义：先验证金币、输入材料、目标库存和输出容量，再统一提交；任何验证失败都不产生部分扣除。

## 11. 保存、异常与恢复

存档至少包含：

- 玩家金币和库存；
- 市集库存、当前价、当日账本和 7 日历史；
- 重要 NPC 的金币、库存、生产与计划；
- 建筑生产队列、剩余时间和暂存输出；
- 当前订单、合同、商队和事件；
- 用于价格与 NPC 决策的随机状态或已生成结果；
- 经济数据版本号。

异常保护：

- 金币、库存、订单量和生产数量不得为负数。
- 生产输出满仓时暂停，不吞材料。
- 基础种子和关键工具不会永久断货。
- NPC 经营失败后缩小生产或接受有限救助，不永久破坏关键产业。
- 老存档缺少新字段时使用稳定默认值，并执行版本迁移。
- 日结过程必须具有日期标记，同一天读档不得重复结算。

## 12. 性能与模拟频率

- 重要 NPC 每日执行一次完整经营决策。
- 玩家交易只更新相关商品账本，不立即重算所有 NPC。
- 普通居民按群体结算。
- NPC 决策可以分帧或错开执行，避免跨日瞬间卡顿。
- 市场历史仅保留 UI 和平衡需要的窗口，默认 7 天。

## 13. 验证标准

至少进行一次连续 28 个游戏日的自动经济模拟，并验证：

- 无玩家参与时 NPC 市场仍能持续运转；
- 基础商品不会永久断货；
- 倾销会压价，供应减少后价格会逐渐恢复；
- NPC 原料短缺会形成订单，交付后可恢复生产；
- 加工产品并非在所有行情下都优于直接出售原料；
- 不存在购买原料、加工并立即出售的无限套利；
- 五类主要经营路线能覆盖长期成本，且无唯一压倒性路线；
- 价格始终位于各自上下限内，单日变化不超过限制；
- 任何交易、生产失败或满仓场景都不造成金币或物品丢失；
- 保存与读取不会重复结算、刷新订单或改变已确定价格。

核心回归测试应覆盖：

- 单一金币权威来源；
- 买入、卖出、滑点和库存守恒；
- 日结顺序与价格平滑；
- NPC 库存消费、生产、订单和交付；
- 生产队列的原子输入与满仓暂停；
- 商队缺货保护；
- 存档迁移与同日幂等；
- 固定随机种子下的可重复 28 日模拟。

## 14. 完整经营闭环

```text
采集与种植
→ 建筑自动生产
→ 加工与合成
→ 玩家和 NPC 消费／交易
→ 市场形成新库存与价格
→ 价格引导下一轮生产决策
→ 盈利投入扩建和自动化
```

该闭环允许玩家选择采集建材、农业食品、花卉蜂业、矿业制造或果园加工等不同路线，同时通过 NPC 竞争、有限流动量和供需变化保持长期选择空间。
