# 3D 农庄首轮模型预览

用户已选择在现有项目的新 3D 分支上制作玩家、树木、田地和谷物，先看效果；承接上一轮提出的独立第三人称测试场景方案。

采用暖色、简化轮廓的卡通立体风格。玩家保留草帽、米色衬衣、蓝色背带裤、棕靴的识别特征；树木有枝干和分层树冠；田地有厚度和垄沟；谷物包含绿苗与成熟麦穗。与仅替换图片相比，真实网格支持自由观察；与整体重建相比，独立场景能先验证效果，保留既有游戏逻辑。

交付可编辑 Blender 源文件、可重复生成的 Blender Python 脚本、独立 GLB 资产，以及 Godot 第三人称预览场景。预览支持移动、转镜头、缩放、跳跃和复位；界面提供中文操作说明。摄像机需有碰撞回缩。首轮为模型和操控预览，不连接原有存档、种植交易或 NPC Agent。

模型单位为米，GLB 为 Y 向上，玩家正面朝 +Z，脚底原点，角色含帽约 2.08 米高。场景地面覆盖 X/Z ±22 米，初始玩家 (-2, 0, 4)。玩家模型包含 Idle/Walk 动画。环境 GLB 包括树木、田地和谷物布置，独立资产可后续重复使用。

保留 main 和既有开发分支；在 feature/3d-farm-preview 工作。验证使用 Godot 实际资源导入、场景运行、物理/镜头检查及实际渲染截图；Blender 源文件可重新打开。原游戏主场景保持可运行，预览通过专用启动脚本进入。
