# 紧凑经济与生产界面设计

日期：2026-08-08
状态：已完成视觉确认，等待书面规格复核

## 1. 背景

当前市集和建筑生产界面接近全屏，采用多列软件面板式布局。它们会与顶部资源信息、右侧经济快捷入口和底部操作栏争夺空间，部分分辨率下还会被 HUD 覆盖。大量边框、标题和纵向文字也使界面更像管理软件，而不是游戏内的操作面板。

本次改造把两类界面统一为居中的紧凑“工坊面板”：保留现有暖色手绘材质，但采用接近 macOS 的扁平层级、细边框、柔和阴影和稳定布局。市集的价格走势成为中央主要信息；生产界面改为一眼可读的投入、加工、产出流程。

## 2. 目标

- 市集与生产面板居中显示，不再铺满视口。
- 在支持的分辨率与 UI 缩放下，面板不与 HUD 的顶部、右侧和底部可见区域重叠，也不再被 HUD 遮挡。
- 市集、订单、合同、服务使用真正的 Tab 页；生产、建筑状态使用同一套 Tab 视觉语言。
- 所有 Tab 标题尺寸一致，切换时不位移、不缩放。
- 选中 Tab 与内容页视觉相连，并具有克制的浮雕层次。
- 市集中央使用平滑曲线展示最近 7 个游戏日的价格历史。
- 生产界面在单屏内清楚表达配方、投入、产出、队列与成品收取。
- 保留现有经济、交易、生产、确认弹窗和键盘操作逻辑。

## 3. 非目标

- 不修改市场定价、NPC 行为、库存或生产耗时规则。
- 不增加超过现有 7 日历史的新市场数据。
- 不重新设计整个游戏 HUD、建造菜单或通知中心。
- 不为本次改造新增写实材质或大型图片资源。
- 不改变订单、合同、服务和生产系统的业务能力。

## 4. 总体视觉方向

采用已确认的“A：工坊木牌”结构，并将表现收敛为轻量扁平风格：

- 主面板使用温暖的纸张底色，外围保留少量木色作为游戏世界的视觉连接。
- 所有结构边框为 1 px 低对比细线；不使用 3–4 px 粗描边。
- 主面板只使用一层柔和短距离阴影，避免厚重的多层投影。
- 圆角统一为 8–12 px；内容卡片不重复堆叠边框。
- 颜色承担主要状态表达，尺寸和位置保持稳定。
- 文字保持清晰，不添加模糊、发光或重描边效果。
- 保留现有经济主题的棕、米白、草绿和金色，但降低饱和度与对比度，使界面更接近 macOS 的平整层次。

### 4.1 设计令牌

| 用途 | 规格 |
| --- | --- |
| 主纸张背景 | `#F4E3BA` |
| 内层浅色背景 | `#FFF2D5`，内层卡片透明度 88% |
| 主文字 | `#49362A` |
| 次要文字 | `#75604D` |
| 选中/正向状态 | `#789563` |
| 金币/当前曲线节点 | `#C7933E` |
| 卖出/警告状态 | `#A77948` / `#A65E50` |
| 常规边框 | 主文字色 22%–32% 透明度，1 px |
| 主面板阴影 | 深棕 16% 透明度，偏移 `(0, 4)`，`shadow_size` 8 px |
| 标题字号 | 26 px |
| 分区标题字号 | 20–22 px |
| 正文字号 | 18 px |
| Tab 与主要按钮字号 | 20 px |

这些值由共享 `economy_theme.tres` 提供，场景只覆盖真正特殊的尺寸，不在多个场景中重复硬编码颜色。

## 5. 面板尺寸与 HUD 安全区

### 5.1 桌面布局

- 设计基准为 1920×1080。
- 市集主面板上限为 1080×600；生产主面板上限为 980×560。
- 面板在 HUD 可用区域内居中，而不是简单按整个视口居中。
- 面板外围至少保留 20 px 安全间距。
- 背景遮罩透明度从当前约 65% 降至 25%–32%，使 HUD 和游戏世界仍可辨认。
- 模态层继续拦截世界与底层 HUD 输入；HUD 可见不代表可在模态界面打开时误触。

### 5.2 响应式布局

`EconomyLayout` 负责根据视口、UI 缩放和 HUD 占位计算可用矩形。面板尺寸先应用设计上限，再收缩到安全矩形内。

- 宽布局：逻辑宽度不小于 1500 px，市场保持三列，生产保持三段结构。
- 紧凑布局：逻辑宽度小于 1500 px，商品列表与详情/交易继续使用现有抽屉切换语义；生产区域允许内部滚动，但标题、主要操作和关闭按钮始终可见。
- 1280×720 是最低验证分辨率。此尺寸下不允许控件越出主面板，也不允许面板与可见 HUD 区域相交。
- UI 缩放继续支持 0.8–1.4；改变缩放或窗口尺寸时保留当前 Tab、商品、配方、滚动位置和键盘焦点语义。

HUD 安全区通过布局接口集中提供，不能在市集和生产场景中分别复制一组魔法偏移量。

## 6. Tab 页设计

### 6.1 结构

市集外壳包含四个 Tab：市集、订单、合同、服务。建筑外壳包含生产和建筑状态两个 Tab。Tab 只切换现有 `PageHost` 内的内容，不创建新的全屏窗口。

### 6.2 尺寸与状态

- 同一 Tab 栏内所有标题固定为 104×42 px。
- Tab 之间保持 6 px 间距，基线完全一致。
- 切换时不得改变 Tab 的尺寸、纵向位置或字体大小。
- 未选中 Tab 使用浅木色或低对比米黄色底色。
- 选中 Tab 使用与内容页相同的纸张底色，并使用草绿色文字或轻微绿色强调。
- 选中 Tab 的底边为透明，使其与内容纸面连成一个整体；内容面板对应位置不得出现横向接缝。
- 所有外边框保持 1 px。

### 6.3 轻浮雕效果

“浮雕”只用于建立层级，不恢复厚重按钮风格：

- 顶部使用一条低透明度高光。
- 左右边使用轻微暗线。
- 未选中 Tab 可带 1–2 px 的短阴影，表现为压在面板后的标签。
- 选中 Tab 与内容页共享同一背景和阴影方向，不出现独立悬浮块。
- Hover 只提高背景亮度约 5%；Pressed 只短暂降低亮度，不做位移。

### 6.4 输入与无障碍

- 保留 `Tab` / `Shift+Tab` 焦点移动和 `Enter` 激活。
- 焦点环使用 2 px 草绿色描边，只在键盘导航时显示。
- 选中状态不能只依赖细微色差；同时由连接到内容页的轮廓关系和 `button_pressed` 状态表达。
- 交易确认弹窗打开时，其他 Tab 继续被阻止切换。

## 7. 市场界面

### 7.1 信息结构

宽布局分为三列：

1. 商品区，约占 24%。
2. 行情区，约占 49%。
3. 交易区，约占 27%。

列间距统一为 10–12 px，只使用必要的浅色分区背景，不给每条信息增加独立粗边框。

### 7.2 商品区

- 顶部使用紧凑分类选择：原材料、农产品、加工材料、食品与手工品、稀有品。
- 分类在空间不足时可横向滚动或折叠为选择器，不纵向占用大块空间。
- 每个商品行显示图标、名称、当前参考价、涨跌方向和玩家持有量。
- 选中商品使用浅绿色底色和 1 px 绿色轮廓。
- 商品列表独立滚动，禁止水平滚动。

### 7.3 中央行情曲线

- 中央区域标题显示商品名、“最近 7 日”、当前中间价与涨跌百分比。
- 使用现有市场历史数组和日期/原因数据，不引入新的数据源。
- 折线改为平滑曲线。实现时用 7 个原始数据点生成平滑路径，但 Hover 命中、日期、价格和变化原因仍对应原始数据点。
- 曲线使用草绿色 2 px 线条，下方可填充不超过 12% 透明度的同色面积。
- 最新节点使用金色突出；其余节点默认弱化，仅在 Hover 或键盘聚焦时放大。
- 图表底部显示供给、需求和库存状态；不显示密集刻度。
- 数据不足 2 天时显示单点和“历史积累中”，不绘制误导性趋势。
- 所有价格相同时，曲线保持在中线，不产生除零或夸张波动。

### 7.4 交易区

- 显示玩家持有量、市场存量、买入/卖出单价、数量选择和预计总价。
- 买入和卖出并列为两个主要动作，颜色分别为草绿和暖棕。
- 大额交易继续使用现有确认弹窗；确认弹窗限制在主面板内部，并保持焦点陷阱。
- 成功和失败反馈显示在交易区按钮下方，不扩张整个面板。

### 7.5 订单、合同与服务

- 沿用同一主面板、Tab 栏、标题区和滚动容器。
- 各页内容允许独立滚动；切换 Tab 不改变外壳尺寸。
- 现有选择、签约、服务解锁和错误状态保持不变。

## 8. 建筑生产界面

### 8.1 信息结构

宽布局分为三段：

1. 左侧配方选择，约占 25%。
2. 中央制作预览与操作，约占 45%。
3. 右侧生产队列和成品仓，约占 30%。

顶部显示建筑名称、生产状态和效率，关闭按钮固定在右上角。

### 8.2 配方区

- 每个配方行显示成品图标、名称以及一行简化的投入/产出摘要。
- 选中态与商品列表一致，使用浅绿色底色和 1 px 轮廓。
- 配方较多时列表内部滚动，不推动中央操作区。

### 8.3 制作预览区

- 用“投入 → 加工 → 产出”的横向流程代替当前底部长文本堆叠。
- 投入与产出使用现有物品图标或统一的小型游戏化图形；数量紧邻图标。
- 中央加工节点根据建筑类型显示简化图标，例如石窑使用火焰/热气符号。
- 耗时、当前可制作批次和材料缺失信息放在流程下方。
- 批量数量、最大值和“开始生产”集中在同一区域。
- 材料不足时保留流程预览，缺失材料用红棕色标出，并禁用开始按钮。

### 8.4 队列与成品仓

- 右上显示生产队列，包含产物、剩余时间和细进度条。
- 右下显示成品仓，包含物品图标、名称、数量、容量和全部收取。
- 现有点击单项收取与全部收取行为保持不变。
- 收取失败时在成品仓内部显示原因，不创建额外大弹窗。

## 9. 动效

- 面板打开：140 ms 淡入并从 0.98 缩放到 1.0。
- 面板关闭：100 ms 淡出，不延迟恢复游戏输入。
- Tab 切换：内容区进行 100 ms 交叉淡化；Tab 本身不移动。
- Hover/Pressed 颜色过渡：80 ms。
- 曲线切换商品时可在 140 ms 内淡入新路径，不使用从零绘制的长动画。
- 动效中断时必须直接落到最终状态，不得阻塞交易或生产输入。

## 10. 组件边界与数据流

### 10.1 共享外壳

市集和建筑界面共享以下视觉职责：

- `EconomyLayout`：计算 UI 缩放、响应式模式、面板上限和 HUD 安全矩形。
- `economy_theme.tres`：提供纸面、细边框、按钮、Tab、选中项和焦点环主题变体。
- 各顶层场景：负责标题、Tab、关闭按钮、内容宿主和打开/关闭动效。

业务面板不自行计算全屏锚点，也不重复定义 Tab 颜色。

### 10.2 市场数据流

`MarketSystem` 提供商品状态与历史 → `MarketPanel` 选择和格式化当前商品 → `MarketPriceChart` 绘制曲线与 Hover 信息 → `TradePanel` 负责数量、报价、确认和反馈。

本次只改变节点组织和展示，不改变报价或成交入口。

### 10.3 生产数据流

`ProductionSystem` 与 `BuildingInstance` 提供配方、队列和存储快照 → `BuildingProductionPanel` 选择配方并渲染三段布局 → 原有请求方法继续负责开始生产、单项收取和全部收取。

事件总线监听和刷新时机保持不变。

## 11. 错误与空状态

- 无可交易商品：商品区显示紧凑空状态，中央曲线和交易按钮进入禁用状态。
- 无历史价格：中央显示“历史积累中”，不绘制伪造曲线。
- 无可用配方：配方区显示空状态，中央显示该建筑暂不可生产。
- 队列为空：队列卡片保留最小高度并显示“当前空闲”。
- 成品仓为空：显示“暂无可收取产物”，全部收取按钮禁用。
- 面板内容溢出：只允许指定列表或内容页滚动，不允许控件越出纸面。
- 系统引用缺失：沿用现有配置失败返回值，面板不打开，不显示半初始化界面。

## 12. 验收标准

### 12.1 视觉与布局

- 1920×1080 下市集不超过 1080×600，生产不超过 980×560。
- 1920×1080、1600×900、1280×720 以及 UI 缩放 0.8、1.0、1.4 下，面板不与可见 HUD 区域相交，内部控件不越界。
- 主结构边框均为 1 px；焦点环可为 2 px。
- 所有同栏 Tab 尺寸相同，切换前后位置不变。
- 选中 Tab 与内容页之间没有可见接缝，并保留轻微高光和短阴影层次。
- 市场中央曲线在正常、单点、平价和 7 点波动数据下均正确显示。

### 12.2 行为

- 市集、订单、合同、服务切换保持原有状态和键盘顺序。
- 交易确认期间不能切换 Tab，关闭确认后恢复正确焦点。
- 商品选择、数量修改、买入、卖出和反馈行为不变。
- 配方选择、批量设置、最大批量、开始生产、单项收取和全部收取行为不变。
- 窗口缩放不丢失当前 Tab、商品、配方和滚动状态。

### 12.3 测试与截图

- 扩展 `test_economy_ui_responsive.gd`，覆盖面板上限、HUD 安全矩形、Tab 等尺寸和无越界。
- 扩展 `test_market_price_chart.gd`，覆盖平滑路径、单点、平价、最多 7 点以及 Hover 原始数据映射。
- 保持并更新 `test_building_economy_ui.gd`，验证新节点结构下的生产与收取生命周期。
- 更新 `capture_economy_ui.gd`，至少输出市集正常态、市集交易确认态、生产进行态、成品待收取态和 1280×720 紧凑态截图。
- 完成自动化测试后进行截图视觉复核，重点检查 HUD 避让、中文清晰度、Tab 接缝、细边框和曲线占比。
